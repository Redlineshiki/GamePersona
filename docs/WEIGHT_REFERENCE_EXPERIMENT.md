# 连续W参考验证协议 v1

2026-10-14，运行前固定。用户授权试验“总有效时长权重W=Σln(1+t)替代N作为主要参考条件”。贡献、标签、输入充分性和类型规则保持不变；本轮为隔离实验，不替换网站。

## 定义、拟合和候选

W只累加共同计分集合G的游戏基础时长权重，不是总小时数，也不把十二维证据相加。小时按共享口径量化，单游戏W权重量化到1e-10后整数求和；SQL与Python逐用户核对W、N/H/E。E仍为Σln(1+t)×标签权重。N≥5仍是资格门槛，不参与连续参考坐标。

沿用838349名拟合人口、旧N/H分层按组最多5000名的58405名确定性拟合样本。逐人从原共同游戏重建W；以旧组全量人数/抽样人数校正抽样率。旧N/H组只用于抽样。冻结当前标签、对数时长无封顶、覆盖≥0.8、未知时长≤0.2、集中度≤0.8、类型80/20和容差10。

主候选为仅log1p(W)上的biweight加权经验CDF，带宽0.10/0.20/0.35。次候选同时使用log1p(W)、log1p(H)，带宽(0.10,0.40)/(0.20,0.65)/(0.35,1.00)。核权重、并列中位秩、有效参考至少200、退化/范围外未知均沿用前轮；W-only不检查H外推，因为H不是该模型的条件，仍报告输入覆盖。没有总体回退或自动放宽带宽。

先评估三个W-only候选，再评估三个W/H候选；通过全部门槛时优先W-only中最小带宽，再考虑W/H。没有通过候选则冻结W-only 0.10作失败诊断，不事后添加候选或放宽门槛。

## 校准和留出

使用前轮相同500名calibration随机用户，以及N=9/19/49/99各最多25人、H=100/500/1500/5000各25个边界案例，便于校准对照。参数选择仅使用calibration，Steam示例不参与。

冻结选择后，evaluation用新盐weight-reference-evaluation-v1排序，取新的500名随机用户并取同样边界案例。排除v1最早500名evaluation用户及前轮N/H实验650名evaluation用户，合计1150名已查看用户。对旧已查看用户的排除以原键SHA-256完成；N/H/E证据在冻结前不读。

预检发现排除后evaluation没有剩余N=99的合格用户。因此新的独立N边界只覆盖9→10、19→20、49→50，各25例；99→100以未参与选型的真实Steam账号17个6分钟扰动作迁移诊断。不能宣称有新的群体99→100独立证据。evaluation样本仍来自同一评论数据集，不是新外部数据。

## 验收和诊断

沿用前轮门槛：500人至少20人12维可展示、至少一维支持≥80%；±10%时长变化中位数≤5/P95≤15、失去支持≤20%；类型一致≥80%（至少40次原类型扰动比较）。N边界和H边界分别P95≤5、最大≤10、失去支持≤20%；无可比数据不算通过。

随机化PIT十等分偏差不超过正式参考+0.02，至少10维有≥200位置且标准差≥10，避免恒定50分假稳定。不把此诊断解释为心理效度或推荐预测能力。

对新留出用户同时评估固定正式参考、冻结的前轮N/H平滑模型和本轮W模型；三者的稳定性直接比较使用三者都可展示的共同维度，另披露各自支持与失去支持。强删除扰动只诊断。

报告新增0.1小时游戏的W实际变化，零证据→少量正证据与正→正证据的分位变化分别诊断。固定E/H而只改变W的反事实用于区分参考条件效应与经验CDF零值并列跳变，不作为真实玩家输入。W的小变化不保证分位一定小变化，尤其有大零值并列时。
