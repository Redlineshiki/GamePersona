# 第三阶段实验协议 v1（运行前登记）

2026-10-14。固定输入：stage1-kaggle-v3-20261014、stage2-features-v1-20261014。
此协议的门槛是实验性产品工程目标，不是心理测量准确性或喜欢概率验证。

## 切分与泄露隔离

SHA-256(`gamepersona-stage3-split-v1:` + user_key) 前 8 个十六进制位转无符号整数取模 100：0～59 拟合、60～79 校准、80～99 独立评价。用户不跨集合；以排序后的 Parquet 及样本键内容哈希固定。先选配置并冻结，再读取独立评价指标；若独立失败，不回调同一独立集。

全量聚合读取所有 clean_records。N<3 的用户只报告数量/损失，不进入候选参考；未知/隔离数据另报告。参考拟合对充分性合格用户按条件组固定 SHA-256 顺序保留最多 5000 人，每人一观测，完整组人数与抽样人数分别保存。5000 使最小秩分辨率至少 0.02 分位点，并限制启动内存；小组不重复采样填满。

校准和独立评价各取 SHA-256 顺序前 500 名 N≥5、覆盖≥0.8 的用户，另输出全量资格和组支持统计；同一版本评价样本定义不随候选变化。样本上重算原始记录，并用共享评分验证 SQL 对齐。Steam 账号仅作外部迁移诊断，不进入拟合/校准/独立集。

## 候选与固定选择规则

时长函数：log1p 无封顶、封顶 100、封顶 200；线性无封顶仅作集中度对照。x、规则不变。

分组：固定 N 下界 [3,5,10,20,50,100] 和 H 下界 [0,100,500,1500,5000]；对照为拟合集 N、log1p(H) 的 0/50/80/95 分位下界（去重，保留 N≥3）。区间左闭右开；最末区间仍检查拟合组真实 min/max H、N，不接受无限外推。v1 不合并稀疏组；不足返回 null。

充分性候选单因素比较，避免无法解释的组合搜索：基线 N≥5、覆盖≥0.8、参考≥200、最大单维贡献≤0.8、未知比例≤0.2；分别比较 N≥3、覆盖≥0.9、参考≥500、集中≤0.6、未知比例≤0。这些门槛均为候选。

组内某维所有证据相同则该维退化；此外报告最大并列比例和不同值数，不因稀疏 G 强行赋值。分位使用固定量化证据中位秩。类型比较 75/25 和 80/20；混合容差 5/10。先选择评分与分组，再选择充分性与类型；每步只使用校准样本。

## 预声明目标

- SQL/Python 的 N、H_ticks、十二维 evidence_ticks 对照必须 100% 相同；版本离线重算必须 identical。
- 校准及独立样本各至少 200 人，其中至少 20 人十二个分位全部可展示；对合格评价样本，至少一维可展示的比例≥80%。同时披露整体过滤损失，不以这些指标冒充总体支持率。
- 对原本可展示、且 ±10% 时长扰动后仍可展示的维度，分位差绝对值中位数≤5、95 分位≤15；同时报告失去支持的比例，要求≤20%。这个目标限制小记录误差引起的界面跳动，不代表真实偏好稳定。
- 删除一个总证据贡献最大的游戏为较强扰动，只报告变化与失去支持比例，不设伪精确效度目标。
- 类型选择以 ±10% 扰动后已生成类型的保留一致率≥80%为目标（至少 20 个完整类型才评价）；若样本不足则不宣称类型稳定，类型仍为实验性可选摘要。
- 不用删除游戏后变化来反向修改特征；在线迁移、稀疏 G 与作者时长解析风险持续记录。

候选依上述目标筛选；同等目标通过时优先对数无封顶、固定分组、基线充分性、80/20、容差10。无封顶对数未通过时选择分位扰动95值更小的通过候选；无候选通过则明确第三阶段未通过，不借降低验收门槛通过。独立测试不重新选型。

输出：全量计数、候选/选择依据、校准与独立结果、退化与支持地图、真实账号报告、协议和模型哈希、代码版本与运行资源。正式目标不包括推荐预测实验。
