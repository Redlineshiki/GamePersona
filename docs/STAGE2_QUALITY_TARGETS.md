# 第二阶段自动规则验收规范

版本：`stage2-tag-support-v1` / `stage2-achievement-v1`，2026-10-14（Asia/Hong_Kong）。按用户确认的方案取消人工标注、人工修订、人工校验集、Cohen κ、人工真值误差及高置信准确率门槛。本规范替代此前候选目标；旧第一阶段快照中的候选目标保留为历史记录，不改写。

## 含义与规则

- 十二维为原八维加独玩、社交、竞争、合作，表示标签支持程度，不是经测量的机制强度。
- 两源按 AppID 取标签并集，统一大小写、空白及配置明确列出的同义词，不模糊匹配。SteamSpy 仅使用正票标签，Kaggle 不补票数；同名、同义及两源重复不叠加。
- 直接证据 1.0、相关证据 0.5、宽泛证据 0.25，每维取最大值。首版 48 条逻辑规则及解释见 `gamepersona/rules/tag_rules_v1.json`，不依据统计自动调权。
- 有可用标签但某维未命中记零，表示零标签证据；两源均不可用时十二维未知。全零向量保留但不纳入玩家画像。后续玩家评分使用正时长、十二维完整且非全零的共同集合。
- `complete` 包含全零向量；`eligible` 再排除全零。正证据率不是机制存在率或准确率。

## 自动验收

| 检查 | 通过条件 |
|---|---|
| 配置 | 十二维固定、ID 唯一、标签维度不重复、同义词不冲突、合法权重及非空理由 |
| 追溯 | 正值均追溯到原标签、来源快照、命中规则和权重；零值追溯到可用标签集与无命中结果 |
| 聚合 | 重复和同义词不增分，票数不改强度，无关标签不改值；新增支持标签不降值 |
| 边界 | 值在 [0,1]，竞争合作可同时高；不从缺失推断相反端；未知、全零及源状态分别保留 |
| 覆盖 | 候选全集、热门、分层、账号及账号新增集合分别报告三种来源模式、完整与可计分覆盖、未知、全零、逐维正证据、新增命中及未映射标签 |
| 成就完整性 | 定义和玩家列表按唯一名称精确匹配，标记仅接受整数 0/1；无成就、失败、不完整和真实零解锁分开 |
| 成就计算 | 每款先算完成率，再按 ln(1+min(小时数,100)) 加权；无有效分母不出分 |
| 充分性与敏感性 | 报告游戏数、游戏及正时长覆盖、有效样本量和最大权重占比；比较无上限、50、100、200 小时上限 |
| 可重复性 | 固定规则及实际消费的输入文件和清单哈希，离线重算记录、指标、报告完全一致，篡改拒绝 |

覆盖率只描述支持范围，不设通过猜测或扩大标签含义满足的比例门槛。执行检查不能证明偏好推断准确，不输出未经验证的准确率、置信概率或正式分类阈值。

## 成就小样本

使用本地已授权账号及固定 Steam 快照，将正时长游戏按时长、AppID 排序，按秩分低中高三组，组内按固定 SHA-256 顺序各选最多五款。响应移除密钥和 SteamID；恢复时验证输入和账号绑定，刷新终态失败使用新快照。

指标使用独立集合，不要求十二维完整。高分粗略对应偏全成就型，低分粗略对应偏主线型，也可能是尚未完成或其他玩法，不证明通关。样本分数不冒充完整游戏库结果；匿名 Kaggle 用户不映射 SteamID，成就指标不套评论样本分位。

历史时长解析风险及评论样本迁移偏差仍影响第三阶段，见 [第一阶段证据核查](STAGE1_EVIDENCE_RESEARCH.md)。本阶段不生成用户十二维参考分位或完整产品报告。
