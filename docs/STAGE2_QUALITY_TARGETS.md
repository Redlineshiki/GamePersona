# 第二阶段候选质量目标登记

登记日期：2026-10-13。第一阶段交付的候选目标，尚不是已通过的模型指标。独立标注或规则核验尚未开始。第二阶段在确认特征尺度、分组和可用证据后冻结这些目标及版本；变更需要说明理由并另建核验版本，不能看过独立结果后降低目标。

## 样本与证据

- 从第一阶段固定游戏集合中确定 150 款人工校验游戏：100 款用于规则调参，50 款用于独立核验。按热门、分层长尾、标签稀疏、来源不一致与标签缺口覆盖选样；保存 AppID 清单、选样理由和固定种子。
- 调参集与核验集不得重叠。独立集在规则调参前固定，人工依据和分歧保留，不以调参结果代替独立核验。
- 每款游戏、每个维度记录证据、判断和置信程度。缺少证据记未知；只有明确机制依据才给已知低值或零值。两名标注者先独立判断，再记录协商结果。
- Kaggle 标签补充、SteamSpy 票数以及商店机制说明分别记录来源和时间。不用某标签缺失证明反向维度成立。

## 候选门槛

| 指标 | 候选目标 | 统计要求 |
|---|---|---|
| 八维值追溯性 | 所有已知特征值 100% 有证据与规则版本 | 未知不能填零；强制排除无证据输出 |
| 单维特征可用率 | 热门集合至少 90%，分层集合至少 80% | 八个维度分别报告；账号新增游戏另报，不混入基础分母 |
| 标签稀疏及无标签游戏 | 明确未知率、补充证据成功率和无法支持范围 | 不设用猜测“补齐”的覆盖目标 |
| 人工独立一致性 | 每维加权 Cohen κ 至少 0.60 | 采用有序等级时适用；报告等级分布、样本量和不确定性，退化时记不可计算 |
| 独立规则误差 | 每维平均绝对误差不超过 0.15，严重误差比例不超过 5% | 仅在特征尺度冻结为 0–1 时适用；严重误差定义为绝对差至少 0.50，未知与缺失另报 |
| 高置信输出质量 | 每维错误比例不超过 10% | 冻结高置信定义和错误判定；不能在失败后把错误输出降置信以规避统计 |
| 可重复性 | 相同输入快照、规则及版本结果完全一致 | 已知值、未知状态、依据和报告均核验 |

50 款独立游戏不足以证明精细游戏类别的总体误差；每组均展示分母和区间，样本过少时补充新独立样本，不把一个总体平均值当作所有维度和类别均通过。以上阈值是首轮候选，需要在读取独立结果前定稿。
