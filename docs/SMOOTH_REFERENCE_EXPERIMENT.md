# N/H平滑条件参考验证协议 v1

2026-10-14，运行前固定。用户授权“验证第一种”：保持贡献、标签、资格和类型门槛，只验证连续N/H参考。当前网站、旧参考、旧报告均不替换。

## 假设和候选

坐标为log1p(N)、log1p(H)。对每个参考用户使用两坐标紧支撑biweight核的乘积：K(u)=(1-u²)²，|u|<1；其余为零。边缘权重与一阶导数都趋于零。按加权中位秩估计各维条件分位，保留零值和并列质量，不平滑结果证据轴。

固定候选带宽(N,H)：(0.25,0.40)、(0.40,0.65)、(0.60,1.00)，不在独立结果之后添加候选。带宽单位是log坐标半宽，不是小时。

拟合沿用v1拟合集与按组最多5000人的确定性样本，但重建逐人N/H/E。每条样本乘以该旧组全量人数/抽样人数，以纠正跨组取样率差异；旧组只用于抽样，无任何查询组切换。加权有效参考数(sum w)²/sum(w²)至少200，否则未知。查询超出拟合样本实际N/H范围仍未知；没有总体回退或扩大带宽救场。集中度>0.8、输入充分性、退化规则保持不变。

## 切分

旧calibration切分按v1固定顺序前500人用于候选选择。另按N=9/19/49/99各最多25人、距H=100/500/1500/5000最近各25人作边界诊断，均来自calibration。

选择冻结后才读取evaluation证据。独立随机样本500人使用新盐smooth-reference-evaluation-v1确定顺序，并排除v1已查看的evaluation前500人。独立边界样本以同样边界规则选取，但也排除旧500人，不参与选型。它们来自同一数据来源的新留出用户，不是新的外部数据集。

Steam示例只用于外部迁移诊断，不参与参数选择。17款特征可计分的零时长游戏分别改为0.1小时。用户群的N边界测试加一款尚未观察、特征已知的游戏，时长0.1小时；H边界测试同比缩放已知小时到边界±0.1小时。所有证据均用原共享评分重算，不直接修改E/N/H凑结果。

## 校准及门槛

保留原工程目标：500人至少20人12维可展示、至少一维支持率≥80%；±10%时长扰动维度差中位数≤5、P95≤15，失去支持≤20%。类型一致率≥80%，至少40个原类型扰动比较才判定。

新增边界目标：N、H边界两侧可比维度差P95≤5分位点，最大≤10；对失去支持的比例仍要求≤20%。N和H分别报告，避免汇总掩盖边界问题。无可比边界数据不能算通过。

防止恒定分位“假稳定”：在未按集中度筛选的充分性/参考可用维度，计算随机化PIT=F(E-)+u·P(E相等)，u由用户键和维度的固定SHA-256产生。报告十等分频率与偏差，十二维平均十等分绝对偏差不超过旧参考+0.02；至少10个维度有≥200个位置，并检查分位标准差≥10。PIT是条件参考校准诊断，不是推荐效果或心理效度。

候选满足全部选择门槛时，优先最小带宽；没有候选通过时冻结最小带宽作为失败诊断，仍完成独立核验，不宣称验证通过，不用独立结果继续调参。

删除最大总证据游戏仅诊断。原评分SQL/Python的N/H/E必须一致；方法单元检查涵盖加权并列、抽样率校正、参考有效数、核边缘连续性、退化和超范围。

## 显式假设与限制

局部玩家的条件分布足够相近、抽样校正有效，是需要由校准指标检查的假设。游戏数是离散变量，平滑条件不保证所有新增游戏影响趋于零；分位轴仍有经验秩台阶。资格/参考有效数的可展示门槛仍允许可用↔未知，必须单独报告。

What did we assume that we didn't write down? 上述局部相似性、抽样率、有效支持、零并列、边界测试及迁移限制已显式写出。此实验不能修复标签语义、未知游戏、评论样本向完整库迁移、实际模式时长和挂机问题。

方法背景：[条件核分布估计](https://www.statsmodels.org/stable/generated/statsmodels.nonparametric.kernel_density.KDEMultivariateConditional.html)。本实验实现为加权经验条件CDF，未直接使用statsmodels或对证据值做连续KDE。
