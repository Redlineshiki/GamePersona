## 样本、过滤与资源

处理 41,154,794 条规范化记录、13,781,059 名有观察记录用户；冲突的 42 条记录不计有效时长。共同计分至少一款游戏的用户 12,898,503 人。为限资源，仅 N≥3 的 3,236,702 人物化四种候选：拟合 1,941,851、校准 647,383、独立评价 647,468。

基线 N≥5、覆盖≥0.8 后，拟合 838,349、校准 278,994、独立评价 279,424 人。这些分别约占物化样本 43.17%；不能用已合格样本的支持率替代原始全体用户支持率。v1 固定 22 个非空条件组，从拟合部分按组 SHA-256 顺序最多抽取 5000 人，总计 58,405 个参考观测；每用户只计一次。校准和独立各用预声明固定顺序前 500 名合格用户执行原始记录扰动核验。

配置 DuckDB 2 GiB 上限、单线程；排序与整数累加固定输出。聚合快照 1,129,699,427 bytes，参考快照 64,708,035 bytes，私人账号报告快照 607,738 bytes（不含 spill）。这是配置及产物占用，不是测得的峰值内存。Parquet 和 manifest 哈希固定数据、切分和版本。

## 冻结模型与适用范围

选择对数无封顶与固定 H/N 分组，基线候选通过工程目标，按协议优先保留简单基线；100/200 小时封顶、线性对照、分位边界和单因素门槛对照全部记录在 selection.json。没有通过改变标签规则扩大支持范围。

| 参数 | 冻结值 |
|---|---|
| 模型 / 评分 | model-stage3-v1 / stage3-evidence-v1 |
| 贡献 | ln(1+t)*x；小时 1e-8、贡献 1e-10 整数量化 |
| N 下界 | 3 / 5 / 10 / 20 / 50 / 100；展示需 N≥5 |
| H 下界（小时） | 0 / 100 / 500 / 1500 / 5000 |
| 覆盖 / 未知时长 | 至少 0.8 / 比例不超过 0.2 |
| 参考观测 / 最大贡献 | 至少 200 / 单维最大占比不超过 0.8 |
| 高、低 / 混合容差 | 80、20 / 分位差绝对值≤10 |

区间左闭右开，末段仍核验组内实际 H/N 最小最大范围。组不足、退化、超范围或单维集中返回 null，不回退总体分位。高低/混合切点是工程实验配置，不能解释为认证人格类别。模型和参考在读取独立样本前已写入快照；独立结果未用于重新选型。

| 指标 | 校准 500 人 | 独立 500 人 | 目标 |

SQL/Python 四候选×500 用户：2000 次 N/H_ticks/十二维 evidence_ticks 对照全部相同。相当强的删除扰动仍造成明显变化，不能把小扰动测试当成偏好稳定性或置信概率。

真实账号 N=99、H=3261.8167 小时、正时长覆盖 91.6412%，命中条件组 `4:3`，4456 个拟合参考观测；十二个分位均可展示。G/O 差值位于混合区间，完整类型 null。账号未参与拟合、校准或独立评价。
