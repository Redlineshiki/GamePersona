## 字段与来源限制

作者固定 commit `41acb9fbe0bcfe9d9ca6ff2300e96531ad97a583` 的采集、转换与导出管线证实 `hours` 为十进制小时，来自保留该行采集观测时网页显示的累计值。逐行采集时间未导出，不能解释为评论创建时长或共同截至 ZIP 日期。

该历史解析器可能丢失千位逗号前的数字，并将失败解析默认成零。保留来源原值，无法逐条反推恢复；单位已核实不代表每行数值准确。`review_id` 是导出生成 ID，匿名 `user_id` 是索引编码，均不能在无映射证据时跨版本稳定关联。第三阶段参考分布需单独评估这些来源风险。

用户已确认本项目使用 Kaggle 与 SteamSpy 进行非商业调取，运营者判断和本地审计范围已单独保存；没有将其写成 SteamSpy 官方许可声明。
